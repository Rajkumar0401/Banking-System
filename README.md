# Banking System
it is command line banking system which manages person  bank account offer services fetching balances,withdrawing,depositing

Core concept use - Object Oriented programming

key features:
 > Data isolation utilizing protected attributes('_balance') to restrict acess outside class context.
 > Automatic assignment of unique 6-digit tracking identifiers upon account instantiation.
 > Intter object communication allowing secure, validated fund transfers between distinct account instances.
 > Keeps transaction history tracking logs for every financial event.
